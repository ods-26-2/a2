As informações de como executar e como funciona está presente em seu respectivo documento no diretório /docs.

Mas, para facilitar, para rodar o módulo A2 local liberação de catraca, entre no diretório, e com o docker desktop rodando, execute: docker compose up --build

Lembrando, para que o A2 local funcione, o módulo DetectorQr de I6 precisa estar rodando alimentando o barramento (kafka) com dados dos QR.
