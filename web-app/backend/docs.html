Documentacao da API

Endpoints liberados para uso com chave de API (header X-API-Key).

Autenticacao

Envie a chave no header X-API-Key em todas as requisicoes.

curl -X POST https://seu-dominio/api/external/users \
  -H "Content-Type: application/json" \
  -H "X-API-Key: SUA_CHAVE" \
  -d '{"cpf":12345678900,"password":"senha","is_recurring":true}'

POST /api/external/users

Cria ou atualiza um usuario. A validade e a data de inicio podem ser enviadas no mesmo body.

{
  "cpf": 12345678900,
  "password": "senha123",
  "is_recurring": true,
  "specific_date": "2026-10-29",
  "expiration_date": "2026-12-31",
  "access_days": [0, 1, 2, 3, 4],
  "access_hours": { "start": "08:00", "end": "18:00" }
}

access_days: dias autorizados (0=Seg ... 6=Dom). Lista vazia gera mascara de dias = 0.

expiration_date: obrigatorio para acesso fixo (data de termino).

DELETE /api/external/users/{cpf}

Remove um usuario pelo CPF.

curl -X DELETE https://seu-dominio/api/external/users/12345678900 \
  -H "X-API-Key: SUA_CHAVE"
